Instruction Manual

THRIVE Console

The backend where staff and faculty manage the THRIVE student hub — its content, records, and day-to-day operations.

Version 1 · 12 Sep 2026 · covers the admin-console build

1. What this is

The THRIVE Console is the control panel behind the student app. From one place you can edit what the assistant knows, review and correct its answers, manage courses, advisors, events and student records, and run maintenance jobs. It runs at the web address /admin/ on the THRIVE server.

There are two kinds of user:

  • Admin  Full access — every record, plus Content management and Operations.
  • Faculty  Scoped access — read the curriculum and review/correct the bot's answers.

2. Getting in

  1. Open the console at https://rsm-vnijs.ucsd.edu/thrive/admin/ (or, when testing locally, http://127.0.0.1:8000/admin/).
  2. Sign in with the username and password you were given.
  3. You'll land on the console home, which lists the sections you're allowed to use.
If you see a login page again after signing in, your account isn't in a console group yet. Ask an administrator to add you to THRIVE Admin or THRIVE Faculty.

4. Common tasks

Edit the catalog Admin

  1. Open Content management.
  2. Under Catalog, click the file to edit (courses.json, careers.json, or bundles.json).
  3. Make your change in the editor. It must stay valid JSON.
  4. Click Validate & save. The console checks the JSON, saves the file, and refreshes the bots' caches so the change is live.
For course facts that come from a syllabus, the durable path is to edit the syllabus and then run Rebuild catalog on the Operations page, rather than editing courses.json by hand.

Re-ingest the corpus Admin

  1. Update the source markdown for the corpus on the server (under data/corpus/).
  2. Open Content management → Corpus re-ingest.
  3. Choose the directory that changed, then click Re-ingest.
  4. Wait for the confirmation. Re-ingest re-reads, re-chunks, and re-embeds the documents.
Important: on the live server, re-ingest must run with the production model backend so the new text is embedded the same way as everything else. If in doubt, ask the maintainer before running it in production.

Review and correct a bot answer Faculty Admin

  1. Open Answer review.
  2. Filter or search to find the answer you want (by topic, route, or whether it was refused).
  3. Open the turn to see the question and the bot's reply.
  4. In the Corrections box, add a note describing what's wrong and what's correct, then Save. Your name and the date are recorded automatically.

Note: corrections are recorded for review today; feeding them back into the bot's answers is a planned next step.

Run a maintenance job Admin

  1. Open Operations.
  2. Find the job you want (rebuild catalog, refresh jobs, retry notifications, refusal report, export evals, run evals, seed demo).
  3. Click Run. The job runs and its result is shown at the top of the page.

Manage a record (course, advisor, event, …) Admin

  1. Click the section on the home page (for example, Courses).
  2. Use search and the filters on the right to find a row, or click Add to create one.
  3. Edit the fields and Save. Related items (a course's meetings, an advisor's slots) are edited inline on the same page.

Give someone console access Admin

  1. Open Authentication → Users and find the person (they must have signed in at least once, or be created here).
  2. Set Staff status on, so they can reach the console.
  3. Add them to the group THRIVE Admin or THRIVE Faculty, then Save.

5. Good habits & safety

  • Catalog edits go live immediately — double-check JSON before saving.
  • Corpus chunks are shown read-only on purpose; change corpus text by editing the source and re-ingesting, not by editing chunks.
  • Run re-ingest and heavy Operations jobs at quiet times; they run while you wait.
  • Student records contain personal information — only admins see them, and only for legitimate program work.

6. Troubleshooting

SymptomFix
Sent back to login after signing inYour account isn't in a console group. An admin adds you to THRIVE Admin or Faculty.
"Bad Request (400)"You opened a web address the server doesn't recognize. Use the exact console URL.
A section is missing from your home pageYour role doesn't include it. Faculty see the curriculum and Answer review only.
"Not saved — invalid JSON"The catalog edit has a JSON error; the message points to where. Fix it and save again.
An Operations job reports an errorThe message shows why. Note it and send it to the maintainer.
