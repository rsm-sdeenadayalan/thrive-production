# UC San Diego Web Proxy

Last Updated: June 28, 2023 11:14:10 AM PDT

Learn about the Web Proxy service.

## Off-Campus access not available

Web Proxy service connecting off-campus to campus systems is not available. Use the following instead:

### From off-campus to campus

-   Use the [UC San Diego VPN service](https://blink.ucsd.edu/technology/network/connections/off-campus/VPN/index.html).
-   [Talk with Library Support](https://ucsd.libanswers.com/) about access options for their resources

### From campus to off-campus

-   Refer to your browser's support for instructions or contact your local system administrator to find out if web proxy service is available through your department.

For questions or assistance with connections, contact the [ITS Service Desk](https://support.ucsd.edu/its/), (858) 246-4357.
