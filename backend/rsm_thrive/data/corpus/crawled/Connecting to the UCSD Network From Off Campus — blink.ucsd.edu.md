# Connecting to the UCSD Network From Off Campus

Last Updated: July 26, 2022 2:15:14 PM PDT

Give [feedback](https://eforms.ucsd.edu/view.php?id=252329/)

Find options for accessing UC San Diego network resources from off campus using Internet service providers (ISPs) other than UC San Diego (e.g., Spectrum, AT&T, Cox).

## [Connect using the UCSD Virtual Private Network (VPN).](#)

With VPN, you can access UCSD services safely from off campus. Traffic between your remote machine (off-campus or wireless) and campus passes over a single encrypted connection, and your remote machine has a UCSD IP address.

-   To access, see [VPN at UCSD](https://blink.ucsd.edu/technology/network/connections/off-campus/VPN/index.html).

## [Determine which SMTP server to use.](#)

-   See [Sending E-mail from Non-UC San Diego Internet Service Providers](https://blink.ucsd.edu/technology/email/tasks/ISP.html) to determine the correct SMTP server for your ISP.
-   See [Configuring Your E-mail Client](https://blink.ucsd.edu/technology/email/tasks/clients/index.html) for instructions on configuring the most commonly used mail clients. Review the steps for Send and Receive for your client.

For more information, contact the [ITS Service Desk](https://support.ucsd.edu/its), (858) 246-4357.
