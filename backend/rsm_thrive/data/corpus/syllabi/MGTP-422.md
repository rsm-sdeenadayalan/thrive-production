Develop an understanding of transaction cycle processing steps and data. Gain hands-on
experience processing transactions in a manual accounting information system and
analyzing transaction data using Microsoft Excel, SQL, and Tableau.

- processing transactions in a manual accounting information system
- completing source and destination documents

DESCRIPTION
Develop an understanding of transaction cycle processing steps and data. Gain hands-on experience
processing transactions in a manual accounting information system and analyzing transaction data using
Microsoft Excel, SQL, and Tableau.
OBJECTIVES
At the close of Systems, Processes, and Technology for Accounting you will be able to:
• Use manual accounting information systems to process transactions, including completing various
source and destination documents, recording transactions in journals, and posting to ledgers.
• Describe basic relational database concepts.
• Describe basic principles of visual perception and design thinking related to data visualization.
• Identify appropriate visualizations for different data types and best practices for creating
visualizations.
• Analyze transaction data using Microsoft Excel, SQL, and Tableau:
Excel
o Nested if statements, and/or logic, vlookup, average, averageif, sum, sumif, stdev, min, max,
count, countif, left, right, len, find, conditional formatting, date, datevalue, year, month, pivot
tables, and simple macros.
SQL
o Create SELECT queries with: from, where (with =, is, >, <, in, between, like, and/or), order by, as,
top, round, concatenate, substring, instr, trim, length, soundex, isnull, and nvl.
o Create aggregate queries using group by (with avg, count, max, min, and sum aggregate
functions) and having and where.
o Use joins (inner, outer, and cross joins) to combine multiple tables
o Create subqueries and views.
Tableau
o Join tables using both inner and outer joins, calculate fields using IF logic, string and date
expressions, and formulas, and correctly classify fields as dimensions or measures.
o Perform interactive data visualization to perform exploratory and confirmatory data analysis of
transaction data including understanding pills, marks, different charts and chart formatting, filters,
aggregations, control charts, table calculations, ranking, top, LOD expressions, etc.

Cases/Assignments/Skills Assessments
Systems Understanding Aid (SUA) - Transaction processing systems are used to record and process
transactions such as sales orders and purchase orders. The SUA case is a hands-on exercise that
provides in-depth understanding of records (journals and ledgers), documents, and processes steps in an
AIS. While collaboration in the form of discussion of the cases is allowed, each individual should
complete his/her own work and copying each other is not allowed (I).
Analyzing Transaction Data
You will learn to analyze transaction data using three tools, Excel, SQL, and Tableau. Each of these tools
will be introduced using an ungraded take-home assignment followed by a graded skills test (a shorter
version of the take-home assignment containing similar problems to the more difficult exercises from the
take-home assignment).
Excel - Excel is extensively used by business professionals and employers more or less expect that you
know how to use Excel. This assignment will introduce you to Excel and also give you hands on
experience with some of the more advanced data analysis functions in Excel. Some of the advanced
features you will learn include vlookups, pivot tables, string and date functions, sumif and sumifs, and
nested if statements. The Excel project consists of an ungraded take-home assignment (C) and a shorter
in-class assignment that is graded (I). You do not need to submit the take-home assignment.
SQL - A large majority of business operational data and almost all accounting data are stored in traditional
data systems, such as relational databases. The data in these databases are accessed and manipulated
using SQL. Consequently, SQL skills is one of the most sought after skill by recruiters that hire business
analytics professionals (Mamonov et al. 2014; Wixom et al. 2014). While SQL is widely used, many
accountant are either not aware of the benefits SQL can provide or they lack the skills necessary to use
SQL. You will be introduced to SQL and gain hands on experience using SQL to analyze transactional
data. You will lean a wide variety of SQL features such as joins, find unmatched queries, case statements,
complex where and having clauses, aggregate functions, views, and sub-queries. The SQL project
consists of an ungraded take-home assignment (C) and a shorter in-class assignment that is graded (I).
You do not need to submit the take-home assignment.
Tableau - Interactive data visualization (e.g., Tableau) is increasingly used to also explore and analyze
structured data. Similarly to SQL, interactive data visualization uses filters, joins, and aggregations, but
instead of producing tabular results, results are displayed as visualizations (e.g., diagrams). Interactive
data visualization has quickly gained in importance (Pacampara 2014) and such skills are increasingly
required by employers looking to hire data analytics professionals (Mamonov et al. 2014). Tableau and
other interactive data visualization tools are also increasingly used in both industry and public accounting.
You will learn a number of graph features in Tableau including creating different types of graphs, using the
marks area, using trend lines, using quick table calculations, and creating calculated fields using if logic
and LOD statements. The Tableau project consists of an ungraded take-home assignment (C) and a
shorter in-class assignment that is graded (I). You do not need to submit the take-home assignment.
