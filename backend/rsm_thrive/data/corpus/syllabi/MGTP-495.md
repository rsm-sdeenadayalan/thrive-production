# MGTP 495 — Accounting Data Analytics

Rady MPAc (Accountancy) · offered SP26 · _unit count not stated in the material supplied_

## What this course covers

This course provides a basic understanding of recent technologies used in data
analytics, machine learning, and artificial intelligence, with an emphasis on accounting
data and the accounting profession. It covers statistical tools from regression analysis
to machine learning and reinforcement learning, taught primarily in Python with weekly
readings and group assignments.

## What you should be able to do afterwards

- running simple regression analysis
- setting up and training machine learning algorithms
- explaining machine learning concepts and their limitations
- understanding fundamentals of reinforcement learning
- understanding how neural networks integrate with machine learning and reinforcement learning
- interacting with data science engineers

## Topics covered

linear regression, logistic regression, bias-variance tradeoff, regularization, classification and regression trees, random forests, neural networks, reinforcement learning, dynamic programming, policy gradient.

## Tools used

python, r, canvas.

## Prerequisites

None stated in the syllabus.

## How it is graded

The final grade is 50% group assignments and 50% final exam, with attendance capping the maximum letter grade.

## Workload

Heavy. Graded work consists of weekly group assignments and a final exam, with required weekly preparatory readings.

Course Description
The goal of this course is to provide a basic understanding of recent technologies used in data analytics,
machine learning, and more broadly artificial intelligence. The course covers a wide range of statistical and
artifical intelligence tools, from regression analysis to machine learning as well as reinforcement learning,
with an emphasis on the use of these tools in the accounting profession and on accounting data.
The techniques and vocabulary developed in this course are useful for:
 Understanding high level concepts of machine learning and predictive analytics.
 Developing an intuition of how ML can be used in practice and its limitations.
 Interacting with data science engineers.

Programming language
The course will be taught primarily in the python language, but students are welcome to use their language
of choice for the assignments and exams.

Course Objectives
At the close of this course, you will be able to:
 Run simple regression analysis.
 Understand the main concepts of machine learning methods.
 Setup and train various machine learning algorithms.
 Understand the fundamentals of reinforcement learning.
 Understand how neural networks integrate with machine learning and reinforcement learning.

Course Preparation and Requirements
This course requires weekly preparatory readings and regular group assignments. The assignments are
necessary to properly digest the concepts presented in class, and the outline below precises which concepts
are used for each assignment. The readings and assignments of a given session is supposed to be done and
submitted before the start of the session. For instance, students are required to read chapter 1 of the
ISL book before the course starts.

2 Group Assignments

with questions will be posted on Canvas at least a week before its due date. These questions are designed to

beginning of the class. They will be graded with a numerical grade beween 0 and 100. Note that any
