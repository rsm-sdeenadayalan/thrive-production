# MGTA 463R — Fraud Analytics

MSBA (Rady MS Business Analytics) · offered SP26 · _unit count not stated in the material supplied_

## What this course covers

This course teaches how to build statistical and machine learning models to detect fraud
in data events. It covers problem dynamics, fraud modes, data analysis and preparation,
feature engineering, algorithm choices, and model evaluation, with lectures on both
supervised and unsupervised fraud models. Students complete homework assignments and
projects on real-world credit card, property tax, and application identity fraud data,
including preparing business reports.

## What you should be able to do afterwards

- building fraud detection models
- building supervised and unsupervised fraud algorithms
- handling incomplete data
- encoding complex fields
- preparing data quality reports
- evaluating model performance
- estimating business impact
- writing professional business reports

## Topics covered

fraud analytics, supervised learning, unsupervised learning, anomaly detection, feature engineering, data cleaning, missing data imputation, categorical encoding, model evaluation, forensic accounting.

## Tools used

python, open source machine learning libraries.

## Prerequisites

Students are expected to have good backgrounds in math and statistics, and a working ability in Python.

## How it is graded

Grades are based on total points from ten homeworks (130 points) and class participation (10 points), with final grades assigned by class distribution so about half get As and half get Bs or lower.

DESCRIPTION
In this course you will learn everything you need to know in order to build statistical/machine learning
models to find fraud in data events. We will cover the basics of building fraud models: understanding the
problem dynamics, modes of fraud, data analysis and preparation, building expert variables/features,
different algorithm choices, and measurements of model goodness. There will be ten individual homework
problems that go through the entire process from raw data to finished fraud algorithm. There will be two
projects, one a classic supervised problem on credit card transaction data and the other an unsupervised
fraud algorithm on a NY property data set.
We will talk through in detail several examples fraud problems and solutions, including tax fraud,
application identity fraud, healthcare claims fraud, and credit card transaction fraud. We will cover the
topic of statistical modeling with a drill-down into all steps to building machine learning models. There will
be a high-level discussion of a wide variety of statistical modeling methods, including linear/logistic
regressions, clustering, neural nets, decision trees, random forests, deep learning, boosting and bagging.
The overall fraud solution emphasis will be on creating expert variables/features which are the key to
building successful fraud algorithms.
The lectures will go into detail on how to build both supervised and unsupervised fraud models. When we
have records that are known to be fraudulent (labeled as fraud) then we can usually build supervised
models to predict new fraud instances going forward. In many cases we don’t have labeled fraud records,
meaning we don’t have any or sufficient specific examples of fraud events from the past. In this case we
typically build unsupervised fraud models, where we look for anomalous records that are unusual in some
important way.
Other topics covered will be forensic accounting vs. real-time fraud algorithms, encoding of difficult fields,
imputing missing data values, encoding categorical variables, variable scaling, fuzzy matching/linking,
and preparing Data Quality Reports.
The three projects to be completed are (1) building a real-time credit card transaction fraud scoring
model, (2) finding anomalies/potential tax fraud in a large, messy data set of NY properties, and (3)
application identity fraud. The second project is an unsupervised forensic accounting type problem, and
the first and third projects will be supervised, where we can evaluate the model performance and estimate
the business impact. The data sets are real and come from an open datasets (1) credit card transactions,
(2) NY property tax records and (3) data synthesized from applications for loans and cell phones. For
each of the projects the students will describe and execute the fraud algorithms and prepare a business
reports.
Students are expected to have good backgrounds in math and statistics, and a working ability in Python.
Many assignments will require the use of Python programming.

ASSIGNMENTS
There are ten homework assignments to be done individually. It’s fine to collaborate on any or all the
work, but it’s best for each student to complete each homework as much as possible individually.
Reading Assignments
None assigned at this time but some material may be suggested and provided, such as the HNC Falcon

Class Projects
You will perform three projects on real-world data sets to build working fraud algorithms. The projects will
be completed individually through a series of homework problems.
In the projects you will learn to analyze and clean a large, dirty real data set, and then build a Data
Quality Report describing the data. There will be missing fields that need to be filled in with various
methodologies. You will then build a supervised fraud algorithm on this data, using a proper pipeline of
methodologies: separation of data into training/testing/validation sets, expert variable creation, feature
selection, using a supervised machine learning algorithm, and evaluating the results with various
measures of goodness.
In the second project you will be performing a forensic accounting-type analysis looking for past
anomalies that are candidates for possible fraud transactions.
