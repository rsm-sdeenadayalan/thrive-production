# CSE 254 — Statistical Learning

**4 units** · CSE · offered varies, varies, varies

## What this course covers

Learning algorithms based on statistics: minimum-variance unbiased estimators, maximum
likelihood estimation, likelihood ratio tests, resampling methods, linear logistic
regression, feature selection, regularization, dimensionality reduction, manifold
detection.

## What you should be able to do afterwards

- statistical foundations of machine learning
- rigorous model selection

## Topics covered

estimation theory, maximum likelihood, resampling, regularization, dimensionality reduction, feature selection.

## Tools used
