# MGT 473 — Data Science with Artificial Intelligence

**4 units** · Rady MBA · offered SP26, SP27

## What this course covers

This course teaches business students to manage AI for data analytics, starting from
zero coding experience. Students learn R programming and 'vibe coding'—using natural
language to direct AI agents to scrape data, run causal inference, and build production-
ready analyses. The course progresses from understanding AI to collaborating with,
managing, and promoting AI agents, culminating in building custom GPTs.

## What you should be able to do afterwards

- writing basic r code
- using ai for data analytics
- conducting causal inference
- vibe coding in r
- building custom ai agents
- scraping and analyzing social media data
- designing custom ai experiences
- managing ai workflows

## Topics covered

r programming, data manipulation, data visualization, natural language programming, vibe coding, ai agents, causal inference, web scraping, business analytics.

## Tools used

r, rstudio, slack, claude, chatgpt, vs code, cursor, claude code.

You don't need to be a coder to become a data scientist—you just need to know how to boss one
around. In MGT 473, you'll learn to manage AI the way a CEO manages a team: set the vision,
give the orders, and verify the results. Starting from zero coding experience, you'll go from writing
your first lines of R to directing a full-blown AI data scientist that scrapes live data, runs causal
inference, and builds production-ready analyses—all from plain English instructions. By the end of
the quarter, you won't just be using AI; you'll be building custom AI agents that manage other
people for you. The class replaces exams with weekly quizzes, runs in-class competitions with a
battle-honors leaderboard, and uses business cases from companies like Alibaba and Coca-Cola. If
you've ever felt like data skills are a superpower locked behind a wall of syntax, this course hands
you the key. Business majors, this is your moment: the game has shifted from who can code the
fastest to who can think the clearest, and that's you.
Artificial intelligence (AI) has significantly reshaped analytics. Today's most valuable quantitative
analysts are not distinguished by coding-syntax mastery and cleverness of execution, but by their
ability to quickly extract meaningful insights from data. What employers now prize is logical
reasoning: the skill to direct AI agents effectively, while ensuring your agents are indeed executing
what you instructed them to as you meant them to—that is, verifying “alignment” with your
intentions. AI has also unlocked entirely new kinds of analysis that were heretofore prohibitively

costly. In a world with AI, analysts function more as architects and supervisors than as code
craftspeople.
This course addresses both dimensions: how to work with AI agents to augment traditional datascience workflows, and how to explore entirely new frontiers of analysis that these revolutionary
tools have made accessible.

OVERVIEW
Large language models (LLMs) such as Claude are powerful. To maximize your productivity—and
stay relevant—you should aim to delegate as much of your workflow to these AI tools as you safely
can. These tools are a great equalizer: with the right AI, an inexperienced but thoughtful data
scientist can accomplish almost anything that an experienced data scientist can. Business majors
now stand out as the finest data scientists since the critical analytics differentiator has shifted from
technical expertise to generating useful insights.
This class will make you a more effective user of generative AI—especially in the context of data
analytics. To best use generative AI, we must make one concession: we must transition from
spreadsheets to computer code. Indeed, LLMs are far smarter when they think in terms of a
programming language, such as R, than when they think in terms of Excel. An Excel framing hobbles
an LLM because a language model can’t be trained on ephemeral mouse clicks. There’s a large corpus
of R code online but no corresponding corpus of Excel cursor movements. Accordingly, a large
language model can more deftly manipulate the syntax of a computer language than the options of
a dropdown menu.
In this class, you will learn “natural language programming,” using AI to translate from the English
language to the R statistical programming language. Beginning with foundational R skills (no prior
coding experience required), you will delegate progressively more responsibility to AI agents over
the course of the term. By the end of the class, you will be managing a full-fledged AI data scientist.
Rather than write computer code from scratch, however, you will learn how to “vibe code,” (1)
learning and articulating the desired data transformations in English, (2) using AI to translate the
spoken language into a computer language (specifically R), and (3) coming up with tests for the AI
to demonstrate alignment and accuracy. You will soon be more productive programming in English
than mousing in Excel. (We will confirm this with an in-class demo.)
In years past, this class has been taught where students were allowed to code with Chat-GPT from
the outset. However, this proved to be a mistake, as it’s difficult to learn the basics when AI preempts you with the answer before you have time to think. Accordingly, we will introduce AI into
our workflow more deliberately. Specifically, the class will comprise four chapters, each delegating
progressively more responsibility to the AI.

Chapter 1 is titled “Understanding the AI.” This chapter will teach you the R statistical
programming language—the lingua franca of data science. Just as Latin was indispensable to
Renaissance scientists, proficiency in a statistical programming language, such as R, is indispensable
to modern data scientists. LLMs can translate effortlessly between English and R. One might assume
this diminishes the value of learning R—but the reality is precisely the opposite: LLMs make R
knowledge more valuable. Before AI, learning R didn’t pay off until you could analyze data more
effectively with code than with Excel, a high bar. But with AI, you don’t need to write code to
leverage your R knowledge—you need only to read it. And you don’t even need to grasp everything,
as 10% of R covers 90% of data tasks. Committing this crucial 10% to memory will pay off in the
long run, just as it paid off to memorize the alphabet and the times tables. Memorizing the key R
functions will enable you to quickly parse and verify sophisticated AI-generated code. In short, after
this chapter, you will be able to understand your AI data scientist, which is the first step to managing
it. We’ll learn the basics of R from a new textbook (written by my co-author, at Northwestern
University). Zero programming experience will be expected—we will start from the ground up.
Chapter 2 is titled “Collaborating with the AI.” This chapter will introduce AI your workflow.
You will learn techniques for natural language programming and for assigning empirical tasks to an
AI. You will also learn how to learn from an AI. You will partner with the AI to derive insights
from real business data.
Chapter 3 is titled “Managing the AI.” This chapter will hone your managerial vision. Whereas
chapter 2 focuses on execution—you will be told what to do, and you will have to figure out how to
do it—chapter 3 focuses on leadership—you will have to figure out both what to do and how to do
it. This chapter will test both your design skills and your managerial skills: you will have to
conceptualize the blueprints of your data analysis, and you will have to instruct AI agents to realize
your plans.
Chapter 4 is titled “Promoting the AI.” This chapter will add another layer to the hierarchy,
upgrading your AI from a data scientist to a middle manager. You will learn how to create AIs that
extend your managerial scope. Specifically, you will create a custom GPT to oversee other students
in the class. You will exploit AI’s extraordinary communication skills: rather than micro-manage
your underlings via meetings and memos, you will embed your directives in a custom GPT, which
will oversee the implementation details.

COMPUTING
We will be using two main tools in this class: R for data analysis and RStudio as our programming
environment.
About R. R is a free, open-source statistical software package that is used by most firms on the
frontier of data science and business analytics. Unlike point-and-click platforms (e.g., SPSS, Excel,
Minitab), R has a command line interface that gives the user complete flexibility when carrying out
statistical analyses. This class does not presume that you have any prior experience using R, but it
does presume you have some basic familiarity with analytics (e.g., an introductory statistics class)
and with logic-based programming.
Rstudio. RStudio is a free, powerful integrated development environment that transforms how you
write and organize code. It brings together your scripts, output, visualizations, and files into one
clean interface—making it far easier to stay organized, catch errors, and iterate quickly compared
to running code in a basic console.

Battle honors: Almost every class features an in-class game or competition. Winners earn battle
honors, which are recorded on a class leaderboard and contribute to your participation grade. Most
battle honors follow a two-step process: first, a Challenge Question appears in the slides, and you
post your answer on Slack by the end of class. If you answer correctly, you become eligible for the
Battle Honors Question, where a randomly selected student from the eligible pool must explain what
a piece of code does in a single sentence. Get it right, and the honor is yours. Your battle honors are
displayed as a functional assembly line—a chain of honor names linked with %>% operators, just
like R code—and your score is the total character length of your chain. A leaderboard will be posted
at the midpoint of the quarter, and an awards ceremony will be held during the final class.
